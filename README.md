# AI Resume Analyzer

AI Resume Analyzer is a Flask-based web application that analyzes resumes and provides useful feedback to help improve resume quality and ATS compatibility.

## Features

- Resume PDF upload
- Resume text extraction
- Skills detection
- Resume scoring
- ATS compatibility scoring
- Resume grade
- Missing skills detection
- Improvement suggestions
- Company/job matching
- User signup and login

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- PyPDF2
